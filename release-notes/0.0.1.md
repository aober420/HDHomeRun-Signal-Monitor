## ✨ New Features

- **Live tuner readings:** Automatically refresh channel, signal strength, signal quality, and symbol quality for each HDHomeRun tuner.
- **Reception graphs:** Follow recent signal changes while adjusting your antenna.
- **Connection status:** See idle tuners, reception warnings, stream bitrate, and connection errors.

## 🎨 Improvements

- **Jellyfin 12.2:** Initial beta built for Jellyfin 12.2.
- **Separate plugin:** Install alongside HDHomeRun Free Guide. No guide settings or channel changes are needed.
